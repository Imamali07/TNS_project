# Data

This folder contains the data used by the AI Pharmacy Chatbot.

## Dataset

The project uses the A-Z Medicines Dataset of India.

The original CSV dataset is not included in this GitHub repository because it is a large file.

Dataset source:

https://www.kaggle.com/datasets/shudhanshusingh/az-medicine-dataset-of-india

Download the dataset and place:

`A_Z_medicines_dataset_of_India.csv`

inside this `data` folder.
