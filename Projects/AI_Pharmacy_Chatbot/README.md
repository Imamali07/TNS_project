# AI Pharmacy Chatbot

A RAG-based AI Pharmacy Assistant that provides medicine information using a medicine dataset, FAISS vector search, and a Qwen language model.

## Features

- Medicine information search
- RAG-based retrieval
- FAISS vector database
- Qwen LLM
- Medicine information from a structured dataset
- Unknown medicine handling
- LLM security guardrails
- Hallucination reduction
- Evaluation of retrieval and security

## Technologies

- Python
- Streamlit
- LangChain
- FAISS
- Sentence Transformers
- Qwen
- RAG

## Safety

This project provides educational medicine information only. It does not prescribe medicines or provide personalized dosage recommendations.
