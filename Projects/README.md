# AI Data Pipeline Automation Agent

An AI-powered data pipeline automation system that automatically ingests raw data, cleans and validates it, stores the processed data in PostgreSQL, and enables users to interact with the data using natural language.

The project combines workflow automation, data engineering, RAG, LLMs, SQL agents, and FastAPI to create an intelligent end-to-end data pipeline.

## Problem

Data pipelines often require manual steps for collecting, cleaning, validating, storing, and analyzing data.

## Solution

This project automates these steps and adds an AI layer that allows users to query and understand the processed data using natural language.

## Key Features

- Automated data ingestion
- Data cleaning
- Data validation
- PostgreSQL data storage
- SQL Agent for natural-language data queries
- RAG-based data interaction
- LLM-powered responses
- FastAPI backend
- n8n workflow automation
- Data visualization
- Streamlit interface

## Project Goal

The goal of this project is to build an intelligent, automated, and production-style data pipeline that reduces manual data-processing work and allows users to interact with their data using natural language.
